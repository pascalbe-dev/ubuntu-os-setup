# Sync Intellij settings

- open intellij
- start a sample project (e.g. spring initializr)
- open `File` > `Manage IDE Settings` > `Backup and Sync`
- Enable backup and sync
- log in with the JetBrains account
- make sure, there is a text saying, that the local settings are overwritten
- press okay
- wait for the sync to finish
- restart the IDE
